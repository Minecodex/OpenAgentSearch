# Atlas 工作台

直接打开[交互演示](../demo.html)。HTML、脚本、字体和样式均随仓库提供。界面语言和配色可在顶栏切换。Ctrl/Cmd + K 可定位页面或项目。

## 可复现的操作

| 想看什么 | 操作与结果 |
| --- | --- |
| 只读资源详情 | 在「项目」打开「海岸观测 → 详情」，按名称查看池、成员与字符上限。点击绑定的代理池可继续查看成员及出口状态，使用「编辑配置」进入表单。 |
| 按能力配置 | 在搜索或正文分类查看示例接入点的语言、时间能力、并发与超时。在模型分类查看 Token 预算与凭据操作。测试保存的版本，再从回执打开关联请求。新增 HTTP 接入点可用保留域名 `https://upstream.invalid` 触发离线失败样例。 |
| 项目与选路 | 在「海岸观测」的同一搜索池加入两个搜索接入点，连续运行两次搜索列表，在请求记录中查看两次实际选中的成员。在「语言路由」将英文映射到后续池中的成员，英文请求会直接从首个命中池开始。 |
| 风控和降级 | 把一个 HTTP 搜索接入点的服务基址设为 `https://risk.example.invalid`，将它放在第一池，再运行搜索列表。调用明细显示该次风控和接替它的成员。同池用尽才转入下一池，随后 30 分钟的请求直接跳过被隔离的接入点。内置浏览器可参与两边的降级，并豁免这段隔离。 |
| 调用方上下文 | 在「检索调试 → 综合总结」载入「附近今天的降水观测有哪些？」。打开参数并填 `region=上海`、`current_time=2026-05-01T00:30:00+08:00`。在「响应 → 请求参数」查看问题改写依据，分别检查两个参照均有、仅有一项和两项均空的情况。将来源上限设为 1 并运行，可从回答点进上海示例站 5 月 1 日的观测。候选抽屉显示带地区和日期的查询命中了这篇资料。 |
| 正文与简介 | 选「网页正文」，载入样例 URL，运行后切换 Markdown 与纯文本。综合总结载入「档案缺页的观测索引」，对比项目关闭或开启简介回退时的错误、部分完成和材料标记。 |
| 请求与观测 | 打开请求详情的检索、去重、评分、正文与分段阶段，点击候选，核对命中排名、文内范围和引用。运行观测可以从时间桶进入调用明细，再沿该次调用返回所属请求。查看、筛选或重载观测页面均不影响选路。 |

API 文档中的业务示例可直接载入调试台。请求详情导出可阅读的 Markdown 报告，包含阶段、来源、分段和调用记录。

离线演示提供手工浏览器表单、样例代理绑定和单 URL 展示。正式契约定义 Pod 发现、每条启用的 VPN 及一份共享默认网络每 30 分钟接受 curl 检测、全局可配置的 7 天留存、HTML 的 iframe 原貌回放、Markdown 排版及可选的 `final_url`。部署后的内置搜索与正文由 Kubernetes 中的 Firefox Pod 自动登记；项目绑定两个稳定能力。内置搜索只使用已经完成首次检测的出口，再按结果选择 Google 或百度。正式系统默认留存完整网页材料和模型往返；此离线页面使用合成样本验证交互。第三方接入点由 Rust 直连各自的原生 API。运维调整 Pod 副本即可扩缩容。[部署中的接入点](../01-system.md#browser-discovery) · [原生协议](../04-routing-and-providers.md#native-providers)

配置和最近 100 条互动记录保存在当前浏览器。运行样本含示例查询和网页，资料范围外的 URL 返回可见错误。上游凭据输入、代理口令与一次性项目 Key 只在对话框内使用。部署组件开关仅切换样本可用性。线上路由、模型输出、真实测试和材料可见范围由 Rust 服务提供。[前端实施对照](../11-atlas-frontend-reference.md)

## 构建与测试

在本目录使用 Node.js 24。构建会从两个 OpenAPI 文件生成 API 参考页，并将 React、HeroUI 与字体打包为离线资源。

```sh
npm ci
npm run check
npm run build
npm test
```

端到端测试可使用已安装的 Chrome、Edge 或 Chromium，环境变量 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 可指定其可执行文件。单元测试覆盖配置、改写、路由与证据。浏览器测试从 HTML 入口核对配置写入、路由匹配、调试响应、请求下钻、筛选返回、中英文和窄屏。[第三方许可](assets/THIRD_PARTY_NOTICES.txt)
